Pulse has migrated into F\*
=================================

Pulse is now a core part of F\*!

You can follow the instructions in the [F\*
repository](https://github.com/FStarLang/FStar) to build F\* and it will include
Pulse by default. The [releases](https://github.com/FStarLang/FStar/releases)
and [nightly builds](https://github.com/FStarLang/FStar-nightly/releases) will
also include it.
